🎙️ 說「嘿 小乖」就能問

做一次就好：之後不用打開網頁，直接說「嘿 小乖」，小乖聽完會念答案給你聽。需要 iOS 18 以上。

  1. 打開 捷徑 App，按右上角 ＋。
  2. 搜尋並加入 聽寫文字，語言選 中文（台灣）。
  3. 加入 URL 編碼（會自動接上「聽寫的文字」）。
  4. 加入 文字：先貼上剛剛複製的網址，再在網址最後面點一下，選上方變數 已編碼的 URL。
  5. 加入 取得 URL 內容，再加入 朗讀文字。
  6. 點最上面的名稱，改成 小乖，按完成。
  7. 到 設定 → 輔助使用 → 語音快捷指令，按 加入動作，選捷徑 小乖。
  8. 照畫面念三次 嘿 小乖，完成。

之後說「嘿 小乖」再講要問的事，例如「明天有什麼行程」，一次問一件事。網址裡有你的同步密碼，請不要傳給別人。

📸 說「嘿 小乖 試算」自動讀最新照片

拍好明細表（或截圖）後，直接說「嘿 小乖 試算」，捷徑會自動抓手機裡最新的一張照片傳給小乖，不用選照片。報表會傳到 Telegram。

  1. 打開 捷徑 App，按 ＋，加入 取得最新的照片（數量 1，「包含螢幕截圖」打開）。
  2. 加入 調整影像大小，寬度填 1500（高度留自動）。
  3. 加入 轉換影像，格式選 JPEG。
  4. 加入 Base64 編碼。
  5. 加入 取得 URL 內容：網址貼上剛複製的網址；點「顯示更多」，方法選 POST，要求本文選 JSON，按「新增欄位 → 文字」加四個：
    action 填 ask　key 貼上密碼　ask 填 試算　image 選變數「Base64 編碼的結果」
  6. 加入 朗讀文字，名稱改成 小乖試算，按完成。
  7. 到 設定 → 輔助使用 → 語音快捷指令 → 加入動作 → 選 小乖試算，念三次 嘿 小乖 試算。

也可以在「照片」App 打開明細表 → 分享 → 選 小乖試算（第 1 步改成「接收分享的影像」就能這樣用）。小乖問「現金還是刷卡」時，說「嘿 小乖」再回答就好。
