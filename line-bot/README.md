# 小乖 × LINE／Telegram 設定教學

完成後你可以：

- 在 LINE 或 Telegram 上直接跟小乖聊天，叫它幫你記待辦、排行程、設提醒、寫筆記
- 提醒時間到，小乖會用 LINE／Telegram 通知你（每 5 分鐘檢查一次）
- LINE、Telegram 和網頁版（Assistant.html）看到的是同一份資料，資料存在你自己的 Google 試算表

LINE 和 Telegram 可以兩個都接，也可以只接一個。只要 Telegram 的話，跳過第 1 步和第 4 步，做第 2、3、5 步（要接網頁版再做第 6 步）。整個流程大約 15 分鐘，只需要做一次。

## 1. 建立 LINE 官方帳號與 Messaging API

1. 到 [LINE Developers](https://developers.line.biz/console/) 用你的 LINE 帳號登入。
2. 建立 Provider（名字隨意，例如「彥彬」）。
3. 在 Provider 下建立 **Messaging API** 頻道，這一步會同時建立小乖專屬的新 LINE 官方帳號（名稱可以取「小乖」）。請不要用店裡（莫凡）的官方帳號，避免客人的訊息跑進小乖。
4. 進入頻道的「Messaging API」分頁，最下方的 **Channel access token** 按「Issue」，複製起來備用。
5. 到 LINE Official Account Manager 的「回應設定」：
   - 關閉「自動回應訊息」
   - 開啟「Webhook」

## 2. 建立 Google 試算表與 Apps Script

1. 到 Google 試算表新建一份空白試算表，命名為「小乖資料庫」。
2. 選單「擴充功能 → Apps Script」。
3. 把編輯器裡的 `Code.gs` 內容全部刪掉，貼上本資料夾的 [Code.gs](Code.gs)，按儲存。
4. 左側齒輪「專案設定」：
   - 勾選「在編輯器中顯示 appsscript.json」，回到編輯器，把 `appsscript.json` 換成本資料夾的 [appsscript.json](appsscript.json)（主要是把時區設成台北）。
   - 往下找到「指令碼屬性」，新增兩個：

     | 屬性 | 值 |
     | --- | --- |
     | `OPENAI_API_KEY` | 你的 OpenAI 金鑰（`sk-` 開頭） |
     | `LINE_CHANNEL_ACCESS_TOKEN` | 第 1 步複製的 Channel access token（只用 Telegram 可不填） |

5. 回到編輯器，上方函式選單選 `setup`，按「執行」。第一次會要求授權，依畫面允許即可。
6. 執行完看「執行記錄」，會出現 **同步密碼**，抄下來。試算表裡也會多出「待辦、行程、提醒、筆記…」幾個分頁。

## 3. 部署成網頁應用程式

1. 右上角「部署 → 新增部署作業」，類型選「網頁應用程式」。
2. 執行身分：**我**；誰可以存取：**所有人**。
3. 按「部署」，複製「網頁應用程式網址」（`https://script.google.com/macros/s/…/exec`）。

之後如果改了程式，要用「部署 → 管理部署作業 → 編輯 → 版本選新版本」更新，網址才不會變。

## 4. 接上 LINE

1. 回到 LINE Developers 的「Messaging API」分頁，Webhook URL 填：

   ```
   https://script.google.com/macros/s/…/exec?key=你的同步密碼
   ```

2. 開啟「Use webhook」。
3. 用手機掃頁面上的 QR code 加小乖好友，傳：

   ```
   綁定 你的同步密碼
   ```

   看到「綁定完成」就可以開始聊天了。綁定後只有你能使用，別人加好友也不會回應。

> 按 Webhook 旁的「Verify」可能會顯示失敗，這是因為 Apps Script 會先轉址一次。只要實際傳訊息小乖有回，就是正常的。

## 5. 接上 Telegram

1. 在 Telegram 搜尋 **@BotFather**，傳 `/newbot`，依指示取名字（例如「小乖」）和帳號名稱（要以 `bot` 結尾，例如 `xiaoguai_yb_bot`）。
2. BotFather 會回你一串 **token**（像 `123456789:ABC…`），複製起來。
3. 回到 Apps Script「專案設定 → 指令碼屬性」，新增兩個：

   | 屬性 | 值 |
   | --- | --- |
   | `TELEGRAM_BOT_TOKEN` | BotFather 給的 token |
   | `WEBAPP_URL` | 第 3 步的網頁應用程式網址（結尾是 `/exec`） |

4. 回到編輯器，函式選單選 `setupTelegram`，按「執行」。執行記錄出現 `"ok":true` 就接好了。
5. 在 Telegram 打開你的機器人，按「開始」，再傳：

   ```
   綁定 你的同步密碼
   ```

   看到「綁定完成」就可以聊天了。綁定後只有你能使用。

## 6. 接上網頁版

打開 Assistant.html → 設定 → 「LINE 與雲端同步」，貼上第 3 步的網址和同步密碼，按「儲存並立即同步」。看到「上次同步：…」就完成了。

網頁開著時每分鐘自動同步一次，切回分頁、新增或修改資料時也會同步。換手機或換瀏覽器，只要填同樣的網址和密碼，資料就會跟過來。

## 常見問題

**LINE／Telegram 上可以做什麼？** 傳「說明」看範例。傳「清除對話」會讓小乖忘掉聊天內容，待辦和筆記不受影響。也可以直接傳圖片（可以附一句說明，例如「幫我記下來」），小乖會讀出圖片內容幫你整理，要記的話會存成筆記。語音、貼圖、影片目前還不支援。LINE 和 Telegram 共用同一段聊天記憶，在 LINE 說到一半，可以到 Telegram 接著聊。

**怎麼試算金額和 PV？** 直接傳「草本產品購買明細表」或訂單圖片就會試算（看不出品項時才當一般圖片讀）。收到明細表時小乖會先列出看到的編號和顆數（看不清楚、價目表沒有的會標 ❓），讀錯可以直接打「改 255A 3顆」「刪 270」「加 260 3顆」「第二個月 加 211 3顆」改正；看明細表固定用 gpt-4o（比較準，指令碼屬性 QUOTE_MODEL 可改），一般聊天還是用 MODEL。明細表會讀兩次：讀完再對照圖片核對一次（補漏列、改錯字；指令碼屬性 QUOTE_VERIFY 設 off 可關掉）。Telegram 用「檔案」方式傳照片不會被壓縮，字比較清楚。接著會問四個問題：①現金還是刷卡、②要買多少 PV 或金額（22萬／30萬 PV、「金額 30萬」、「不指定」）、③要買滿幾個月（1／2／3 個月、「照明細表」）、④入會方式（女生：新入會(草本）女＋入會 211、707 各 2；男生：新入會(草本）男＋入會 211、101 各 2；九號：新入會(9號）＋入會 9號兩組 1；舊會員：不加），有按鈕可以點，都回答後才算；兩個都有時先照選的月數算，PV 或金額不夠就自動把月數補到達標為止（一定買到目標）。明細表本身就超過目標時，照 SOP 刪減原則：先刪第三個月（最後一個月份）的產品，基本款 211、300、299A 不刪，一項一項拿掉、拿掉後仍達標才刪，報表會列出拿掉了哪些。明細表上有寫的（例如空白處寫「現金」「22萬」「男」，或各欄「服用 N 月」有填）就不再問，小乖會列出「📝 表上寫了：…」；說明欄先寫好（例如「現金 22萬 3個月 男」）也會直接算，說明欄優先於表上寫的；只寫「照明細表」等於②③都照明細表。說明欄可加「男」「刷卡」「舊會員」「22萬」；也可以直接打字「試算 211 2盒、777Q 1盒」。小乖會列出每項的數量、金額、PV 和總計。AI 只負責看出品項和數量，金額與 PV 由程式照價目表計算。第一次試算時，試算表會自動多一個「價目表」分頁，之後要改價格或加品項，直接改這個分頁就好（欄位：品項｜PV｜金額｜每盒顆數）。明細表會依「每次顆數 × 早中晚時段 × 30 天 × 服用月數 ÷ 每盒顆數」無條件進位算盒數；2711AB、777Q 滿 4 盒自動換組合價；火山甘露每月 1 盒、777Q 每月 2 盒、2711AB 每月 3 盒（至少 3 盒）、168/111/101 每月 2 盒且每 3 個月最多 4 盒；現金時 211 會先扣掉贈品 211(30) 和入會送的盒數（照 SOP「現金購買 211 可少算」）；「保養」欄另外算每月費用。明細表試算會自動加上新入會組合（預設女生：新入會(草本）女＋入會 211、707 各 2 盒；說明欄寫「男」改成男生組合＋入會 211、101；寫「舊會員」就不加）。明細表的試算結果會另外列出「買 1／2／3 個月」各要多少金額和 PV（照表上月份順序取）。說明欄可以加目標 PV（例如「試算 22萬」），小乖會把最後一個有寫顆數的月份拉長到達標為止。結果的格式和規則對齊「彥彬試算系統」的康園試算報表：現金每滿 2 萬送「贈品 211(30)」1 瓶（說明欄寫「刷卡」就不送）、距離 22 萬／30 萬 PV、預估可使用天數（2 字頭品項最高盒數 × 15 天），以及非經理／經理的預計獎金（總金額 × 級距 %，扣稅 10%）。

**試算報表圖片（Telegram）：** 在 Telegram 試算時，小乖會先傳一張「康園試算報表」樣式的圖片，再傳文字明細。圖片是用 Google 簡報畫的，另外會存一份到你雲端硬碟的「小乖試算報表」資料夾（不公開）。第一次使用前，先在 Apps Script 編輯器左側「服務」按 ＋，加入「Google Slides API」和「Drive API」（Drive 用來把報表頁面改成直式；沒加也會出圖，只是縮小放在橫式頁面）；再到函式選單選 `authorizeReport` 按「執行」，允許「簡報」和「雲端硬碟」權限。LINE 也會收到同一張圖片：LINE 只收公開網址的圖片，所以 LINE 試算的報表圖片會在雲端硬碟設成「知道連結的人都能看」（2026-10-14 使用者同意）。

**要換 AI 模型？** 在指令碼屬性新增 `MODEL`，值填 `gpt-5-mini`（預設是 `gpt-4o-mini`）。

**費用？** Google 試算表與 Apps Script 免費。OpenAI 依用量計費。LINE 一般回覆訊息不計費，但提醒用的是「推播訊息」，免費方案每月有則數上限，同一時間到的提醒會合併成一則送出。

**會在哪裡收到提醒？** LINE 和 Telegram 都綁定的話，兩邊都會收到；網頁開著時也會跳提醒，所以有機會收到不只一次，屬正常現象。Telegram 的通知沒有則數限制。

**資料可以直接在試算表改嗎？** 請不要手動改「資料」那一欄，那是程式讀的內容；「摘要」欄只是方便你瀏覽。要改資料請用網頁或 LINE。

**安全性：** 同步密碼等於鑰匙，不要分享給別人。若外流，到指令碼屬性改掉 `SYNC_KEY`，再更新 LINE 的 Webhook URL、重新執行 `setupTelegram`，並更新網頁設定。要換綁帳號的話，刪掉 `OWNER_USER_ID`（LINE）或 `TG_OWNER_CHAT_ID`（Telegram）後重新傳「綁定」。

**小乖可以進 LINE 群組嗎？** 可以，但只有主人能邀請：
1. LINE 官方帳號管理後台 → 設定 → 帳號設定 → 功能切換 →「加入群組或多人聊天室」選「接受邀請」→ 儲存。
2. 每次要邀請前，先私訊小乖「邀請小乖」，接下來 10 分鐘內由主人自己把小乖邀進群組（主人本人要在群組裡）。邀請時間只能用一次。
3. 其他人邀請、或主人不在那個群組、或超過 10 分鐘，小乖一進群組就馬上退出（LINE 不會告訴機器人是誰邀的，所以用這兩個條件確認）。
4. 在群組裡小乖只回主人，而且訊息開頭要打「小乖」；主人打「小乖離開」小乖就退出那個群組。私訊「群組關」小乖會離開所有群組，「群組」看目前在幾個群組。
5. 群組裡的照片不會自動試算，主人要先打「小乖 試算」再傳明細表。

**找資料（分本機和網路）、語音：**
- 「本機找 關鍵字」（或「查 / 找 關鍵字」）：只找小乖自己存的資料：案例庫、待辦、行程、提醒、筆記。圖片／影片案例在 Telegram 會直接把原檔再傳給你；在 LINE 只會說找到幾個（檔案存在 Telegram）。
- 「上網找 關鍵字」：用 OpenAI 的網路搜尋整理重點和來源網址（SEARCH_MODEL 可換模型，預設 gpt-4.1-mini）。本機找完下面也有「🌐 上網找」按鈕。
- 按「📁 本機找」或「🌐 上網找」按鈕再打字或傳語音也可以。
- 案例庫：Telegram 機器人看不到你以前的聊天紀錄，所以要把圖片、影片、文字「轉傳給小乖」（可以一次選很多則轉傳），或傳圖片時說明打「存」，就會存進試算表的「案例庫」分頁（存 Telegram 的檔案編號、說明文字，圖片會請 AI 寫描述和關鍵字，影片用縮圖）。
- 案例分類：存進來時 AI 會自動分到「見證案例／使用前後對比／產品介紹／試算報表／課程活動／其他」其中一類，並記下產品、人物、一句摘要和關鍵字（試算表「案例庫」分頁各有一欄）。分類清單在「案例分類」分頁，可以自己增減。
  - 說明裡打「#見證案例」會直接放進這個分類。
  - 存好後下面會出現「改分類 …」按鈕，分錯了按一下就改；打「改分類 新名稱」會新增分類。
  - 按「🗂️ 案例分類」會列出每個分類有幾筆，按分類就看裡面的案例（最新的在前面）。
  - 「本機找」的結果也會照分類分組。
  - 舊格式的「案例庫」會自動改名成「案例庫（舊）」保留。

**工作表排列：** 所有分頁（待辦、行程、提醒、筆記、刪除紀錄、聊天紀錄、案例庫）都是最新的在最上面、最舊的在下面。舊的聊天紀錄和案例庫第一次用到時會自動整張翻過來。
- 語音：Telegram 和 LINE 都能直接傳語音，小乖先轉成文字（whisper-1，VOICE_MODEL 可換）再照一般訊息處理。
